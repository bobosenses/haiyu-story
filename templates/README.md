# 剧本模板

可直接复制填写的短剧文本模板。默认面向竖屏、单集 **60–120 秒**。括号和空行都是待填项，没有示例成稿。

| 模板 | 何时用 |
|---|---|
| [series-bible.md](./series-bible.md) | 开写之前：世界观、人物、关系、冲突主线 |
| [outline-multi-ep.md](./outline-multi-ep.md) | 多集地图：每集钩子，付费墙可留空 |
| [character-card.md](./character-card.md) | 一个角色一张卡，方便对白和后续生图锁造型 |
| [scene-beat.md](./scene-beat.md) | 一场戏的节拍，先于对白 |
| [episode-script.md](./episode-script.md) | 单集可拍剧本 |

推荐顺序见 [workflows/script-only.md](../workflows/script-only.md)。
