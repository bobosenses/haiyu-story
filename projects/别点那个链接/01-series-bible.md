# 系列设定

> 开写分集之前填完。一个人能在两分钟内读完。细节放角色卡，不堆进这里。  
> 工作流步骤 2 · 对应 short-drama `/plan`

## 一句话

实习生林夏在「今晚不到账就清退」的虚假投资群压迫下几乎转出全部积蓄；室友用可见证据拆穿话术后，骗子与「紧急人事来电」双线封杀求证——她必须学会在极限催促里先停手。

## 形态

| 项 | 填写 |
|---|---|
| 平台 / 画幅 | 竖屏 9:16 / 抖音·快手·视频号类短剧信息流 |
| 单集时长 | 90–120 秒（表演念稿口径） |
| 计划集数 | 8 集（前 3 集硬核闭环单元，4–8 扩线收束） |
| 类型 | 反诈 / 都市现实 / 压迫倒计时 |
| 受众 | 18–35 城市青年；合租/实习/轻度理财焦虑人群 |
| 原著 | 原创 / 不做改编 |

## 世界观（最多三条能拍出来的规则）

1. 骗局发生在「私域群 + 语音催促 + 个人转账」链条里；正规牌照与公开渠道从不要求「禁截图、禁告诉家人、今晚立刻私人到账」。
2. 骗子会同步制造「外部权威」（假人事、假同事截图）打断受害者向真人求证。
3. 拆穿必须靠**屏幕上看得见的证据**（公告、收款方式、催促话术），不能靠主角突然开挂或说教旁白。

不能破坏的事实：

- 林夏不是金融从业者，也不会一夜变专家；她的成长是「先停手 → 会核验 → 敢报警/求助平台」。
- 不展示可复现的钓鱼链接、木马、盗号步骤；账号与收款信息全程打码。
- 周妍不是全知警察，她靠生活常识 + 群内文本拆穿。

## 调性

- 观众每集要感到的那口气：胸口发紧的倒计时，夹杂「差点就按下去」的后怕。
- 要：短句对白、看得见的动作、话术层层加码、证据型拆穿、结尾新问题。
- 不要：长篇普法旁白、羞辱受害者、教学诈骗操作、连续纯解释对白。

## 冲突主线

- 主角欲望：抓住「改变处境」的机会，证明自己不比同事差。
- 对立力量：阿凯团伙（话术压迫 + 信息茧房 + 假权威联动）。
- 全剧问句（结局必须回答）：林夏能不能在下一次「紧急且保密」的催促里，先停手并向可信渠道核实——而不是把信任交给屏幕里的声音？
- 中段必须翻转的一次：第 4–5 集左右——「假人事」被坐实为同伙，或林夏发现群里「已进场同事」根本不是真人；她从被动被救转为主动取证。

## 视觉连续性

- 时代 / 城市 / 季节：当代一线或新一线城市；合租夜；秋冬室内偏冷白光
- 主色或材质：手机冷光蓝白 + 倒计时血红；廉价木质床头、外卖盒、湿发水汽
- 反复出现的物件：倒计时贴纸气泡、群公告置顶句、银行确认键（打码）、湿发/充电器（周妍入场符号）
- 禁止出现：未打码的真实卡号/二维码/可点击钓鱼 URL；血腥暴力；未成年人涉案

## 合规

- 版权与授权：原创；角色与公司名为虚构
- 不写的内容：可复现诈骗教程、真实平台漏洞利用、教人反侦察；不以羞辱受害者取乐
- 若含付费墙：卡在第 3 集结尾「假人事声线与阿凯后台串线被听见」反转之后（可选；本季默认可免费连看前 3）
