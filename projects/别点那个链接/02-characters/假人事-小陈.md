# 角色卡 · 「人事」小陈

## 身份

| 项 | 填写 |
|---|---|
| 姓名 | 来电显示「公司人事·紧急」；自报「小陈」（虚构） |
| 年龄 | 声音感 30 左右 |
| 对外身份 | 林夏实习单位「人事」；实为骗局假权威线 |
| 剧中功能 | 功能人 / 假权威（对手侧） |
| 说话习惯 | 公事腔；短促；用「窗口期」「考核记录」「名额」施压 |

## 戏剧

- 想要（表面）：通知林夏「今晚必须确认某项到账/投资相关材料，否则影响实习」。
- 真正害怕失去：林夏接通后把通话给周妍听、或打回公司总机核实。
- 秘密：与阿凯同伙；来电时机卡在转账被打断的瞬间（EP01 结尾揭示同步性）。
- 开场状态 → 结局状态：可信的职场权威幻象 → 被录音/回拨总机揭穿的假号码话术。
- 不会做的事：提供可核验的工号门户链接（真的）；允许第三方旁听。

## 关系

| 对象 | 称呼 | 张力 |
|---|---|---|
| 林夏 | 林夏同学 | 用实习去留制造恐惧 |
| 阿凯 | （同伙） | 分工：阿凯禁接，小陈制造「必须接/必须听我的」矛盾压力 |

## 语言指纹

- 口头禅或句式：「紧急确认」「窗口今晚关闭」「这是考核记录」「不方便的话我会记一次」
- 绝不会说：「你可以打公司前台转我分机」「请室友旁听也没关系」
- 示例一句（语气，不是剧情）：「林夏同学，你这边今晚有一笔确认，影响到账记录。」
