|---|---|---|
| 60–120 秒能念完（本季声明 90–120） | **通过** | 场次 55+40+10 ≈ 105 秒；对白以短句为主，可删说明不可删冲突 |

| 没有连续多句纯解释 | **通过** | 周妍「第一条/二/三」绑在屏幕动作上，非旁白普法 |

### 相对旧稿的加厚（已应用）

- 话术分层：从众点名 → 清退羞辱 → 否定半仓 → 「剩两个」最后一推。
- 动作可视：备忘录房租、删字、敲 9800、指节发白、拧戒指、夺机、放大公告、按低音量不挂断。
- 拆穿绑证据：禁截图公告、私人转账气泡、极限催促——每条都有屏幕指认。
- 结尾双线：来电 UI + 阿凯禁接同步，避免「只吓一跳」的单薄钩子。

### 修复记录

| 问题 | 处理 |
|---|---|
| 用户反馈旧版「太简单」 | 按节拍重写成三场；加厚对白往返与可见动作（见上） |
| 风险：拆穿变成长篇说教 | 限制为三条短句，各配一个屏幕动作 |
| 风险：银行/收款信息可被模仿 | 全程打码；不出现可点击链接与真实账号 |

**步骤 5 总评：通过**
